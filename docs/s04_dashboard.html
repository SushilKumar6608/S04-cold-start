🎬 S04 — Content Cold-Start Solver using Metadata Embeddings

Embedding-based recommender system that solves the cold-start problem — recommending new content with zero user interaction data. Uses sentence-transformers to embed rich movie metadata (plot, genres, keywords, tagline) into a FAISS vector index. Claude Sonnet enhances vague natural language queries and explains why each movie was recommended. Includes a "New Movie Concept" mode where users pitch an unmade film and find the most similar existing movies.

Cold-start design principle: Traditional recommenders require user history (collaborative filtering) or item interaction data (matrix factorisation). This system uses only item metadata — plot summaries, genres, keywords, taglines — to build a semantic embedding space. A new movie added today with zero ratings can be recommended immediately, purely from its description.
LLM query enhancement: When a user types a vague query like "something scary but makes me think", Claude expands it into a rich, structured description with inferred genres, themes, tone, and keywords — producing a much better embedding match. This bridges the gap between natural user language and the structured metadata space.

Key Findings
Finding 1 — Query expansion meaningfully improves retrieval: A 6-word vague query ("something scary but makes me think") returns similarity scores of ~0.63 with direct embedding. After Claude expansion to a 100-word structured description, scores jump to ~0.71 — a 13% improvement — and results shift from generic horror to specific psychological thrillers.
Finding 2 — Metadata concatenation order matters: Placing the plot overview before genres and keywords gives the embedding model the most context-rich signal first. Titles alone produce poor similarity; adding taglines and keywords lifts semantic precision noticeably, especially for niche genres.
Finding 3 — New Movie Concept mode demonstrates cold-start concretely: Pitching "The Last Diagnosis" (a fictional unmade film about a surgeon discovering unexplained hospital deaths) returned Coma (1978), The Hospital (1971), and The Killing of a Sacred Deer — all genuinely thematically aligned — with zero user interaction data needed.
Finding 4 — Quality filtering is essential: Without minimum rating filtering, ~30% of top-10 results are low-rated or obscure films that technically match the embedding but disappoint users. Over-fetching (50 candidates) and quality filtering to top-5 substantially improves perceived recommendation quality.
