🎬 S04 — Content Cold-Start Solver using Metadata Embeddings

Embedding-based recommender that solves the item cold-start problem — recommending new content before any user interaction data exists. Benchmarked against SVD collaborative filtering on MovieLens 25M: CF covers 0% of new movies; the embedding system covers 100%. Claude Sonnet enhances natural language queries and explains recommendations. Built with Sellpy-style second-hand catalogues in mind — every new listing is cold-start by definition.

Cold-Start Experiment
Setup: SVD collaborative filter trained on 24.4M ratings from 161,557 users — pre-2015 movies only. Test set: 7,890 post-2015 movies. These items never appeared during training — CF has no latent factors for them.
Result: CF coverage on new movies = 0%. Embedding system coverage = 100%. The gap is not marginal — it is total. For any new item added to a catalogue today, CF is completely blind. The embedding system works immediately from the item description alone.
Example — "I'm Not Ashamed" (2016, 7 ratings): CF cannot recommend it. Embedding system returns: We Are Columbine (0.60), She Fought Alone (0.57), Bad Reputation (0.55), The Hunting Ground (0.54), The Unfaithful (0.53) — all thematically aligned, found using only the plot summary and genre metadata.
Why 88.2% of new movies are sparse: Post-2015 movies average 67 ratings vs 452 for pre-2015 movies — a 6.8× gap. Even the movies CF technically saw have unreliable latent factors. The cold-start zone is not a rare edge case — it is the default state for new content.

Real-World Applicability
Sellpy: Every second-hand listing is a unique item with zero interaction history by definition. CF cannot recommend new listings. This system recommends them immediately using title, description, and category — exactly the metadata Sellpy already has.
Streaming (Viaplay): New Nordic original content needs recommendations before any viewing data exists. Embedding on synopsis + genre bridges the gap between launch day and sufficient interaction data.
General pattern: Any platform where new items are added continuously — job boards, e-commerce, research databases, music platforms — faces the cold-start problem. This pipeline transfers directly: replace the TMDB CSV with your item catalogue and re-run.
